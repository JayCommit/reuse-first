# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal appearance,
race, caste, color, religion, or sexual identity and orientation.

## Expected behavior

Be respectful, accept constructive feedback, and focus on what is best for the
community. Harassment, trolling, insulting comments, and publishing others'
private information are not acceptable.

## Contact

Report conduct concerns by opening a GitHub issue:

https://github.com/JayCommit/reuse-first/issues

Maintainers may edit or reject contributions that violate this code.
