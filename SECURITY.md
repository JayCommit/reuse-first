# Security

This project is a local skill and a standard-library indexer. It does not run a
network service and it does not take credentials.

Report a vulnerability privately through GitHub Security Advisories for this
repository:

https://github.com/JayCommit/reuse-first/security/advisories/new

Use GitHub private vulnerability reporting. There is no security email address
for this project. Do not open a public issue for an undisclosed vulnerability.
Do not include secrets, tokens, or private paths in a report.
